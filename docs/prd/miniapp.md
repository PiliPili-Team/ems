# 移动端 Mini App

<span class="badge-planned">待实现</span> **首期交付**（已确认），与桌面端同一发布批次。

## 入口与认证

| 项 | 说明 |
|---|---|
| 入口 | Telegram Bot 的菜单按钮，或命令结果内的内嵌按钮 |
| 认证 | Telegram 提供签名数据，服务端校验后签发短期会话，与 Web 共用会话池 |
| 账号 | 只登录**已绑定**的账号，不自动创建 |

## 页面

| 路由 | 内容 | 对应桌面模块 |
|---|---|---|
| `/m` | 首页：余额、签到、媒体账号摘要 | 积分、我的媒体 |
| `/m/shop` | 商品与我的礼品卡 | 商店 |
| `/m/wishes` | 提交与我的求片 | 求片 |
| `/m/me` | 个人资料、线路切换 | 资料、线路 |

## 布局原则

- 底部标签导航，单列卡片。
- 共用桌面的业务视图，通过断点裁剪，不另写业务逻辑。
- 管理类高风险操作（禁用、链式封禁、红包发行）**不进入** Mini App 与 Bot，只在 Web。

## Bot 命令（背景）

用户侧命令：`/start`、`/new`、`/bind`、`/renew`、`/info`、`/checkin`、`/points`、`/lines`、`/request`、`/help`。命令规格不在本文范围。

## 子功能与交互

| 页面 | 子功能 | 展示 | 交互 |
|---|---|---|---|
| `/m` | 状态卡 | 积分余额、媒体账号状态与到期倒计时 | 点击进入对应页面 |
| `/m` | 签到 | 大按钮，已签到置灰 | 点击后弹出所得积分 |
| `/m` | 快捷入口 | 线路、商店、求片图标 | 点击进入 |
| `/m/shop` | 商品与我的礼品卡 | 商品卡片；礼品卡列表带状态 | 兑换确认弹窗；复制卡号；一键兑换 |
| `/m/wishes` | 求片 | 粘贴 TMDB 链接，预览卡片；我的求片分栏 | 提交；额度显示 |
| `/m/me` | 资料与线路 | 头像、层级、当前线路 | 切换线路；退出 |

## 约束

- 账号、禁用、到期门控规则与桌面端一致：被管理员禁用则全部拒绝；媒体账号到期只限制 Emby 相关能力，**续期始终可用**。
- 未绑定的 Telegram 账号：显示绑定说明与 Bot 深链，不展示业务页面。
- 与桌面共用后端权限与功能开关，菜单项同样按后端下发结果显示。
- 验收包含在[交付范围与验收](/delivery-scope)中。
