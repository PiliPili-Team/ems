# 决策记录

整理自原始设计文档、当前仓库角色矩阵与功能清单之间的差异。以下均已确认，并已回写到对应模块页。**总原则：不交付半成品**——功能上线即包含完整子功能、状态与权限，详见[交付范围与验收](/delivery-scope)。

| # | 议题 | 结论 | 落地位置 |
|---|---|---|---|
| 1 | 普通用户的首页概览 | 新增面向用户的“首页 / 应用中心”，保留不含敏感内容的统计（在线人数、Top5、最近入库）；系统与他人信息只在运营仪表盘 | [P2](/modules/home-dashboard) |
| 2 | 发现的受众 | 以功能清单为准：求片功能开启 **且** 用户有媒体账号才可见 | [P8](/modules/discover) |
| 3 | 音乐检索与已存搜索 | 保留 | [P8](/modules/discover) |
| 4 | 订阅、工作流、日历、整理、站点管理 | 保持移除，不在本文档范围 | [范围](/) |
| 5 | 用户发红包 | 默认仅管理员发行；用户发红包由开关控制 | [P5](/modules/points)、[A2](/modules/admin-commerce) |
| 6 | 媒体账号路由 | 使用 `/my-media` | [导航](/navigation-routes) |
| 7 | 积分调整额度与复核 | 界面显示剩余额度；不要求超管复核（暂定，保留复议）；**必须写审计日志** | [A2](/modules/admin-commerce) |
| 8 | 邀请树与链式封禁 | 查看与封禁（含回滚）**同一阶段**交付 | [A1](/modules/admin-users) |
| 9 | OpenAPI 页 | 内置页面，仅管理员及以上可见 | [A6](/modules/system) |
| 10 | 宿主机文件 | 归入系统区，保持 `/filemanager` 路径 | [A6](/modules/system) |
| 11 | Mini App | 首期交付 | [Mini App](/miniapp) |

## 实施阶段的修订

| 日期 | 模块 | 修订 | 原因 |
|---|---|---|---|
| 2026-10-12 | 我的媒体 | 开通后一次性显示 Emby 初始密码，而非“不回显” | 后端开通响应含 `initialPassword`，不显示用户将无法登录 Emby |
| 2026-10-12 | 我的媒体 | 认领被拒只显示状态，不显示原因 | 用户侧接口无拒绝原因字段 |
| 2026-10-12 | 我的媒体 | 以 `expiresAt` 为空判定永久成员 | PRD “保号模式”与后端 `keepAlive` 语义相反，以后端为准 |
| 2026-10-12 | 线路 | “逐条锁定线路卡片”改为单张“会员线路”提示卡 | 用户侧 `/lines` 只返回可见线路且不含层级要求 |
| 2026-10-12 | 线路 | 当前线路取 `/auth/me.selectedLineId`，延迟取 `/lines.latencyMs` | `/lines` 不含选中标记；账号延迟接口后端仍为 planned |
| 2026-10-12 | 我的媒体 | 认领接口的 401 视为“Emby 凭证被拒”，不触发统一登出 | 后端对 Emby 验证失败返回 `UNAUTHENTICATED`，与会话失效同码，直接走统一处理会让输错密码的用户被登出 |
| 2026-10-12 | 媒体服务器 | 多服务器可添加但只启用一个；服务器编号改为自增整数；账号只在启用服务器上可见 | 实际使用方式如此，账号天然归属某个服务器；未上线，无需迁移数据 |
| 2026-10-12 | 媒体服务器 | 未启用服务器上账号的到期与清除冻结，直到重新启用 | 避免切换期间用户账号被悄悄清除 |
| 2026-10-14 | 全站 | 用户与管理员页面按“对象范围 × 任务”拆分，不按角色拆分；同对象只差读写时用“仅查看”；两侧页面不互放跳转入口 | 见[页面设计原则](/page-design) |
| 2026-10-14 | 推流 | 线路接入范围支持层级与指定用户,用户以数字 UID 保存 | 后端 `allowedUserIds` 已改为接受并返回十进制 UID |
| 2026-10-14 | 推流 | 已停用的节点不能加入线路,前端只提供已启用节点 | 后端对停用节点上线路返回 422 |
| 2026-10-14 | 推流 | 页面无“仅查看”模式 | 后端只有 `admin.config.media` 一个读写权限点 |
| 2026-10-14 | 全站 | 取消用户页与管理页之间的互链入口(“管理线路”“以用户视角查看”) | 两侧分开进入即可,互链多余 |
| 2026-10-14 | 媒体服务器 | 系统中第一台服务器添加后自动启用(由后端保证);已有服务器时仍默认不启用 | 0 到 1 时再手动启用是多余的一步 |
