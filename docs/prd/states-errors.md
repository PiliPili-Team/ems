# 通用状态与错误反馈

## 页面状态

| 状态 | 展示 | 交互 |
|---|---|---|
| 加载 | 列表与卡片用骨架屏，不整页转圈 | — |
| 空 | 说明为什么为空 + 下一步按钮（如“去签到”“清除筛选”） | — |
| 错误 | 局部错误卡，附“重试” | 重试仅重新请求该区块 |
| 仅查看 | 页头“仅查看”标签，写控件隐藏 | — |
| 锁定 | 锁图标 + 原因 + 升级入口 | 跳转商店或说明 |
| 功能关闭 | 菜单隐藏；直接访问 404 | — |
| 离线 | 顶部全局提示条，不清除会话 | 恢复后自动消失 |

## 列表分页

所有记录列表默认**每页 10 条**,可切换 10 / 20 / 50;使用同一个分页组件(总数与范围、页码、每页条数;窄屏紧凑形态)。页码与每页条数写入地址栏,刷新后还原;筛选、搜索或切换标签回到第 1 页;删除使当前页变空时回退一页;翻页时保留旧内容并显示进度,不闪现空态。

有界的选项来源(线路选择、我的媒体账号、下拉候选)、通行密钥与宿主机目录不属于记录列表,不分页。

## 后端错误的统一呈现

| 状态码 | 含义 | 前端行为 |
|---|---|---|
| 401 | 未登录或会话过期 | 保存当前路径，跳转登录 |
| 403 | 无权限 | 页面级：进入 403 页；操作级：toast 说明 |
| 403 `USER_DISABLED` | 用户被禁用 | 强制登出并提示 |
| 404 | 不存在或隐藏 | 404 页（对 admin 查看超管同样表现为不存在） |
| 409 | 版本冲突或资源状态冲突 | “数据已变化，请刷新”，提供刷新按钮；不覆盖用户输入 |
| 422 / 400 | 校验失败 | 按字段回填内联错误 |
| 429 | 限流 | 显示 `Retry-After` 倒计时；相关按钮禁用 |
| 5xx / 网络 | 服务问题 | toast + 重试；相同错误去重 |

错误文案由**错误码**映射到多语言文本，并支持参数插值（如差额 `{shortfall}`）；不直接显示后端的原始消息。

## 表单约定

- 提交中按钮禁用并显示进度。
- 字段错误回填到对应字段；无法定位的显示在表单顶部。
- 有未保存修改时离开页面需确认。
- 幂等操作（兑换、签到）重复点击不会产生重复结果。

## 危险操作

| 级别 | 示例 | 确认方式 |
|---|---|---|
| 一般 | 禁用用户、作废码 | 确认弹窗，说明影响 |
| 重要 | 删除用户、轮换 API Key | 弹窗 + 明确后果文案 |
| 严重 | 剪枝、递归删除目录 | 需输入对象名；展示影响数量 |

## 国际化与无障碍

- 简体中文与 English 全量覆盖；语言包按页面域分组。
- 所有图标按钮有文字提示；状态不只靠颜色表达（徽标含文字）。
