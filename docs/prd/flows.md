# 关键流程

跨模块的用户旅程。每个流程标出涉及的页面与失败分支。

## F1 新用户开通（积分经济起点）

```mermaid
flowchart TD
    A["拿到邀请码"] --> B["/login 注册"]
    B --> C["登录"]
    C --> D{"有媒体账号?"}
    D -- 否 --> E["/my-media 空状态：开通或认领"]
    E --> F["/points 每日签到、领红包"]
    F --> G["/shop 兑换注册码"]
    G --> H["/shop/codes 使用注册码"]
    H --> I["/my-media 显示连接信息"]
    I --> J["开始观看"]
    E -.认领已有账号.-> K["输入 Emby 凭据"]
    K -->|审批模式| L["待审批"]
    K -->|直接| I
    L --> M["管理员审批通过"] --> I
```

- 余额不足：商店按钮置灰，提示差额，引导回积分中心。
- 注册码已被使用：显示错误，码状态刷新为“已使用”。
- Emby 创建失败：注册码**不消耗**，提示稍后重试。

## F2 到期自救

```mermaid
flowchart TD
    A["账号到期"] --> B["Emby 被禁用<br/>播放与改密不可用"]
    B --> C["登录与 Bot 仍可用"]
    C --> D["/my-media 提示：已到期，剩余宽限 N 天"]
    D --> E["商店兑换续期码"]
    E --> F["输入续期码续期"]
    F --> G["账号恢复为正常，Emby 解禁"]
    D -.宽限期满.-> H["清除：不可续期"]
    H --> I["重新开通或认领"]
```

## F3 求片

```mermaid
flowchart TD
    A["发现页搜索 / 粘贴 TMDB 链接"] --> B["解析预览"]
    B --> C{"额度与重复检查"}
    C -- 额度用完 --> D["按钮禁用，显示重置时间"]
    C -- 30 天内重复 --> E["显示已有求片"]
    C -- 通过 --> F["提交，状态：待处理"]
    F --> G["管理员：进行中"]
    G --> H["已处理，用户列表更新"]
    F -.超时.-> I["已过期，管理员可重新激活"]
```

## F4 红包

```mermaid
flowchart TD
    A["管理员 / 用户发红包"] --> B["红包出现在可领列表"]
    B --> C["用户点击领取"]
    C --> D{"结果"}
    D -- 成功 --> E["弹出所得积分，账本记一笔"]
    D -- 已领完 --> F["卡片置灰：已领完"]
    D -- 非目标用户 --> G["提示：专属红包"]
    B -.管理员作废.-> H["剩余金额退回"]
```

## F5 链式封禁

```mermaid
flowchart TD
    A["超管打开用户详情"] --> B["点击链式封禁"]
    B --> C["预览：N 人受影响，管理员与超管豁免"]
    C --> D["输入根用户名确认"]
    D --> E["批量禁用 + 会话失效"]
    E --> F["Emby 联动：最终一致"]
    F --> G["封禁记录列表"]
    G -.误封.-> H["回滚"]
```

## F6 配置一条新线路

```mermaid
flowchart TD
    A["/admin/stream 新建节点"] --> B["选择类型，填写表单"]
    B --> C["设置匹配规则并试匹配"]
    C --> D["保存，热生效"]
    D --> E["新建线路，选择节点并拖拽排序"]
    E --> F["设置接入范围：全员或受限"]
    F --> G["用户在 /lines 看到线路"]
    G -->|会员线路，用户为 normal| H["锁定态，引导商店"]
```
