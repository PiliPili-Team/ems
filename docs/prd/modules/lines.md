# P4 线路

<span class="badge-planned">待实现</span> 后端 `/lines` 与 `/me/line` 已实现。

## 目的

让用户选择播放线路。原则是**对用户无感**：只有一条可选线路时不出选择题。

## 子功能

| 子功能 | 展示 | 交互 |
|---|---|---|
| 单线路模式 | 整页只显示“当前线路”卡片（名称、延迟），无选择器 | 只读 |
| 多线路模式 | 线路卡片列表：名称、延迟徽标、当前选中高亮 | 点击卡片切换；成功提示“下次播放起生效” |
| 锁定线路 | 卡片显示锁图标与所需层级（如 VIP） | 点击不发请求，显示说明并提供“前往商店”按钮 |
| 延迟刷新 | 徽标颜色区分好 / 一般 / 差 / 未知 | 30 秒自动轮询；页面不可见时暂停 |

是否可选由后端 `selectable` 字段决定；返回的列表即最终可见集，前端不二次过滤。

## 角色差异

| 身份 | 看到 |
|---|---|
| user · normal | 仅接入范围覆盖自己的线路；会员线路以锁定态出现（如运营配置允许展示） |
| user · vip / whitelist | 额外的会员线路 |
| 层级到期 | 已选的会员线路回落为默认线路，并提示“层级已变化” |
| admin / super_admin | 与用户相同；线路配置在 [推流节点与线路](/modules/admin-stream) |

## 状态与边界

- 无任何可用线路：显示“暂无可用线路，请联系管理员”。
- 切换失败（线路刚被停用）：提示并刷新列表。

## 依赖接口

`/lines`、`PUT /me/line`、`/media/accounts/{id}/latency`（planned）。
