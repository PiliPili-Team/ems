# P14 礼物

<span class="badge-built">已实现</span> 成员用积分在礼物商店购买礼物,可以收藏、佩戴、转赠,并在礼物市场里互相买卖。礼物分「普通」与「藏品」两类;藏品在每个礼物目录内有唯一编号。本模块与「礼品卡」(兑换码)无关。

## 礼物 `/gifts`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 我的礼物 | 方形卡片网格:图片(款式图 → 封面 → 吉祥物拆礼物插画)、藏品左上角 `#编号`、佩戴中右上角对勾、名称与稀有度 | 点卡片打开右侧详情抽屉(`/gifts/:id`);分页;空状态带「礼物商店」按钮 |
| 礼物商店 | 纯平卡片:图片、名称、款式数 · 剩余 · 已买 x/上限、可转赠 / 可佩戴 / 佩戴加成徽标、价格 | 「购买」打开右侧抽屉:多款式时选款式,价格与余额不足提示固定在底部;已售罄或已达限购时原因取代按钮 |
| 开箱 | 礼物盒摇两下后揭晓款式、稀有度与编号 | 可「跳过」;减少动效时直接揭晓;「查看礼物」进入详情 |
| 详情 | 大图、类别 / 稀有度 / 款式 / 佩戴徽标,编号、持有者、来源、持有自,流转时间线(购买、铸造、转赠、邮件领取、市场售出及成交价) | 持有者可佩戴 / 卸下(同时只佩戴 1 件)与转赠;挂单中的礼物不能佩戴与转赠;时间线中的成员可点开名片,隐藏者显示「匿名用户」不可点;附言只给双方看 |
| 转赠 | 抽屉内表单:成员 UID(实时核对并显示对方名字)、附言(≤200 字)、不可撤回提示 | 确认后礼物归对方并自动卸下,对方收到铃铛通知 |

| 出售 | 详情抽屉内(仅「可出售」的礼物):价格输入、手续费与到手积分实时计算、锁定提示;已挂单时显示「正在出售,价格 x」 | 挂单(已佩戴则自动卸下)、改价、下架;改价时版本不符提示刷新 |

页头:标题在左,分段控件(我的礼物 / 礼物商店 / 礼物市场)在中轴,积分余额在右;手机上余额在第一行右侧,分段控件独占第二行。

## 礼物市场 `/gifts/market`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 列表 | 方形卡片网格(每列至少 10rem):图片、藏品编号、右下价格胶囊、名称与稀有度、卖家(隐藏者为「匿名用户」);自己的挂单显示「我的」徽标 | 点图片打开详情(`/gifts/market/:id`,可看流转记录);「购买」打开右侧确认抽屉;分页 |
| 筛选 | 礼物(商店在售目录)、类别、排序(最新 / 价格升降 / 编号)、价格区间、编号区间、只看我的挂单;条件写入地址 | 宽屏一行排开;手机收进「筛选」抽屉,按钮显示生效条件数 |
| 购买确认 | 大图、卖家、编号、款式与稀有度,底部价格与余额不足提示 | 卖家改价后提交:提示新价格并更新,可按新价再次确认,不会按旧价扣款;成功后礼物飞入「我的礼物」(点按跳过,减少动效时不播放) |
| 市场关闭 | 顶部提示「市场暂时关闭」 | 挂单保留,购买按钮禁用;不能新挂单 |

## 成员名片 `/members/:uid`

只读:头像(右下角是佩戴礼物的小角标)、显示名、UID、佩戴中的礼物、公开的礼物(最多 60 件)。不显示 Telegram、邮箱、媒体账号等账号信息。成员关闭「公开我的礼物」时只显示「这位成员没有公开礼物」,佩戴的礼物仍显示。

## 隐私(设置 → 账户 → 礼物)

- 在流转记录中显示我:关闭后,别人看到的历史与未来记录里本人都是「匿名用户」。
- 公开我的礼物:关闭后名片不列礼物,别人也打不开未佩戴的礼物详情(404)。

## 礼物管理 `/admin/gifts`

页头分段控件:礼物目录 / 持有查询 / 市场;右栏「新建礼物」(需 `admin.gifts.write`)。

- 目录:卡片显示图片、类别与上架状态、已售 · 已发行 · 剩余 · 款式数、价格;「持有者」跳到持有查询,「编辑」打开抽屉。
- 编辑抽屉:三语名称(简体必填,其余留空回落简体)、类别(已发行后锁定)、价格、总量与每人限购(留空不限)、佩戴加成(仅藏品,默认 20%)、上架 / 可转赠 / 可佩戴 / 可出售开关;封面与每个款式的图片(PNG、WebP、GIF、SVG,≤2 MB,SVG 去除脚本与链接后保存)、稀有度、增删款式(编号重复 409,仍有礼物使用的款式不能删)。名称与图片改动立即作用于全部已发行礼物。
- 持有查询:按礼物与持有者 UID 筛选,行内是图片、名称与编号、款式 · 来源 · 日期、持有者名片链接。

- 市场:设置卡片(开放市场、手续费 %、最高价格,需 `admin.gifts.write` 才能保存);下方分段「在售挂单 / 成交记录」,可按礼物筛选。在售挂单可「强制下架」(须填原因,礼物退回卖家并收到通知);成交记录显示卖家 → 买家 UID、时间、成交价与手续费。

## 礼物铸造 `/super/gifts`(仅超管)

- 保留编号:单独编号(≤1000 个)+ 规则(重复数字:三位及以上相同;连续数字:四位及以上逐位 ±1)。默认都为空;自动分配跳过保留编号,修改不影响已分配的编号。
- 铸造:选礼物、款式、可选编号(含保留编号,已被占用 409)与成员 UID。铸造不占总量,计入发行数。

## 规则

- 购买:积分付给系统账户(流水来源 26「购买礼物」);限购按累计购买数计,转出不恢复;总量按商店售出计。
- 编号:每个礼物目录从 1 递增,单写事务保证并发购买不重号。
- 佩戴加成:佩戴可佩戴的藏品时,签到与月度全勤奖励的加成 = 层级加成 + 藏品加成;奖励倍率关闭时一并不计。普通礼物佩戴只展示。
- 邮件附件 4「礼物」:目标是礼物目录,领取时按数量发放该目录第一个款式,藏品分配新编号;目录已无款式时领取失败(原因 8)。
- 市场:只有开启「可出售」的礼物能挂单,价格 1 到 `maxPrice`(默认 1,000,000);每件礼物至多一条有效挂单,挂单期间不可转赠、不可佩戴。购买在同一事务内:买家付价格,卖家得价格 − 手续费,手续费 = ⌊价格 × 费率⌋ 入系统账户(默认 0%,最高 50%),所有权转移并写流转记录「售出」及成交价;流水来源 27「礼物交易」、28「礼物交易手续费」。每次改价使挂单版本 +1,购买须带版本,不符返回 409 `LISTING_CHANGED` 与当前价格;不能买自己的挂单;并发购买只有一人成功。市场关闭时购买与新挂单返回 404,已有挂单保留。卖家在成交与被强制下架时收到铃铛通知。
- 审计模块 17「礼物」:`gifts.buy`、`gifts.transfer`、`gifts.sku.*`、`gifts.style.*`、`gifts.image.*`、`gifts.reserved.update`、`gifts.mint`、`gifts.market.*`(挂单、改价、下架、购买、强制下架、设置)。
