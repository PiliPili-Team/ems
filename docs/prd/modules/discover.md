# P8 发现

<span class="badge-built">已实现</span> 搜索、详情、演职员、人物；`/recommend`、`/discover` 页已移除。

## 可见条件（已确认）

发现相关页面需**同时满足**：后端“求片”功能已开启；当前用户拥有媒体账号。任一不满足时菜单隐藏；直接访问时显示说明页（缺少媒体账号则引导开通 / 认领，功能关闭则 404）。该条件对 admin、super_admin 同样适用，管理员不会因角色绕过。

## 目的

通过 TMDB 搜索与浏览影视，查看详情，并发起求片。

## 子功能

| 子功能 | 展示 | 交互 |
|---|---|---|
| 搜索 | 全局搜索框与结果网格 | 输入后防抖请求；支持电影、剧集、人物 |
| 详情页 `/media` | 海报、简介、评分、季与集信息 | 标签页切换概览、演职员、相似；“求片”按钮 |
| 演职员 `/credits/:paths+` | 头像列表 | 点击进入人物页 |
| 人物 `/person` | 简介与作品列表 | 点击作品进入详情 |
| 已存搜索 `/saved-searches` | 保存的搜索条件列表 | 点击重放；可删除 |
| 求片入口 | 详情页按钮，随状态变化：可求片 / 已入库 / 已求片 / 额度用完 | 点击带入 [求片](/modules/wishes) 页或直接确认 |
| 音乐检索 `/music` 系列 | 专辑、艺术家、详情 | 保留（已确认），可见性同样由功能开关与权限点决定 |

## 角色差异

| 角色 | 差异 |
|---|---|
| user · normal | 满足上述条件时可浏览与求片；资源搜索等会员功能不显示 |
| user · vip / whitelist | 同上，并按功能开关显示资源搜索 |
| admin / super_admin | 同用户 |

## 状态与边界

- TMDB 服务不可用：显示“暂时无法获取”，保留已缓存内容。
- 无结果：空状态建议调整关键词。
- 功能关闭：菜单隐藏，直接访问 404。
- 账号到期或被停用：媒体账号不再有效时，发现与求片入口隐藏，并在首页提示续期。

## 依赖接口

TMDB 目录与人物接口、`/wishes/*`、`/stats/*`。
