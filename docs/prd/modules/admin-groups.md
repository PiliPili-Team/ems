# A8 访问分组

<span class="badge-built">已实现</span> 自定义分组页 `/admin/groups` 与接入范围编辑器的分组选择均已实现。

## 概念

- **分组**把指定的用户编成一组,类似 TestFlight 的测试组:有系统分配的 **Group ID**(数字,从 10001 起自增,永不复用)和可修改的**别名**(如“媒体测试组”),界面统一显示为“别名 #编号”。
- 分组是**全局**的:线路和媒体库的接入范围共用同一批分组。
- 接入范围 = 所选**层级**与所选**分组**,命中任一即放行(OR);用户可同时属于多个分组,多个分组之间同样是“任一即可”。
- 资源上不再逐个指定用户(已移除 `allowedUserIds`)。

## 页面 `/admin/groups`

| 区域 | 展示 | 交互 |
|---|---|---|
| 分组列表 | “别名 #编号”、成员数;“显示已删除”开关 | 点击打开详情;已删除分组以淡色只读显示删除时间 |
| 分组详情 | 别名、创建时间、成员数(含已禁用人数)、正在使用它的线路和媒体库 | 重命名、删除 |
| 成员 | **分页列表**(每页 20)+ 用户名搜索 | 多选后批量移出;“添加成员”打开搜索选择框,可多选后一次加入(单次最多 500 人);不用芯片平铺 |
| 新建 / 重命名 | 别名 1–32 个字符,在未删除的分组中唯一 | 编号由系统分配,创建后不可改 |
| 删除 | 先检查引用:被线路或媒体库使用时**拒绝并列出引用方**;未被使用时需确认后**软删除** | 软删除保留记录与审计,成员关系清除,编号不再复用,别名可被新分组使用 |

窄屏(390px)下列表与详情分两级:先看列表,点进分组后显示详情和返回按钮。

## 接入范围编辑器

线路与媒体库共用:模式(不限 / 受限)、层级芯片、**自定义分组多选**,并显示“当前影响 N 名用户”。口径:所选层级中的活跃用户与所选分组成员取并集、去重,排除已禁用用户;管理员沿用“按白名单层级处理”的既有规则。

## 角色差异

| 能力 | admin | super_admin |
|---|---|---|
| 查看分组、成员、影响人数 | 有 `admin.groups.read` | 是 |
| 创建、重命名、删除、增删成员 | 有 `admin.groups.write` | 是 |

只有读权限时页面显示“仅查看”,写操作控件隐藏。成员候选搜索由分组接口提供(只返回 UID 与用户名),不依赖用户目录权限;非超管看不到超管账号。普通用户、VIP、白名单、匿名访问均被后端拒绝(403 / 401)。

## 状态与边界

- 成员变更会重新发布涉及该分组的媒体库策略,由队列异步同步到各账号的 Emby 权限。
- 用户被删除后自动移出所有分组。
- 单个分组成员上限 10000。
- 已被删除的分组不可编辑、不可恢复。

## 依赖接口

`/admin/groups*`、`/admin/groups/{id}/members*`、`/admin/groups/{id}/candidates`、`/admin/groups/{id}/references`、`/admin/access-scope/preview`。
