# A2 商店、红包与积分运营

<span class="badge-built">红包、签到、积分运营已实现</span> <span class="badge-built">商品管理与卡券管理已实现</span>

## 商品管理 `/admin/products`

页头右侧显示商店状态、“新建商品”和齿轮按钮;齿轮打开高级设置弹窗,内含“商店开放”开关、每日开放时间与开放日期范围(仅在商店开启时可编辑;时间留空表示全天,日期留空表示全日期,含首尾日期,按站点时区判定)。商店实际开放同时受开关、日期与每日时间限制,范围外菜单隐藏且下单/领券被拒绝。关闭只停止购买,不影响已持有的卡。旧地址 `/admin/shop` 自动跳转到这里。

| 子功能 | 展示 | 交互 |
|---|---|---|
| 商品列表 | 与用户商店同一张商品卡:图片区(未上传时为按卡种着色的默认图案)、名称、面值、价格、有效期规则、库存、上下架状态;心愿点数商品注明无卡、不可用优惠券 | 开关上下架;点击编辑 |
| 新建 / 编辑商品 | 顶部图片区(上传 PNG/JPEG/WebP,最大 2 MB,服务端归一化为 WebP;可恢复默认)、类型、名称、面值、价格、库存、有效期规则、开通与续期卡的服务器绑定 | 积分卡价格低于最低价提示下限;心愿点数商品价格必须等于面值、库存无限、购买即时入账,不得使用优惠券;商品保存后图片随之上传,失败时提示 |
| 删除商品 | 行菜单 | 已有订单的商品只能下架;心愿点数的历史订单也阻止删除 |

## 卡券管理 `/admin/vouchers`

按卡券种类分标签:“礼品卡”“优惠券”(新增一种卡券不新增菜单);“发卡”与“礼品卡样式”位于页面标题行右侧。

| 子功能 | 展示 | 交互 |
|---|---|---|
| 礼品卡列表 | App Store 风格卡面网格:按卡种着色的渐变、运营方 LOGO、面值、编号、状态、持有者与兑换者;检索(持有者、兑换者、卡号)、类型与状态筛选 | 列表不含卡号明文;点击卡面进入溯源时间线 |
| 查看卡号 | “查看”按钮,仅未兑换、未作废、未过期的卡 | 需 `admin.shop.reveal`(超管默认有,admin 须被授权);写审计并累加查看次数 |
| 作废 | 未兑换的卡 | 确认弹窗,可勾选退款(从系统账户退还购买价,不可重复) |
| 发卡 | 页头右侧的“发卡”,与页面标题对齐;选择商品与数量;持有者留空创建不记名卡 | admin 可发非积分卡;**积分卡仅超管**,发行时面值计入系统账户;不记名卡归系统内置用户,任何用户可凭卡号兑换 |
| 礼品卡样式 | 页头齿轮左侧的调色板按钮,打开 LOGO 对话框:预览卡面、上传、使用默认 LOGO | 全站一份 LOGO;上传后管理端与用户端卡面立即更新;需 `admin.shop.write` |

### 优惠券标签

分“券模板”“已发出的券”两个子标签;权限同商品管理(`admin.shop.write`)。

| 子功能 | 展示 | 交互 |
|---|---|---|
| 券模板 | 卡片网格:券面、适用范围、获取方式、有效期、已发/已用/总量进度、启用开关;共享券码模板显示券码(可复制)与“已使用 N / 总次数” | 新建、编辑、启停、删除;共享券码模板可打开“使用明细”(用户、订单、时间) |
| 新建 / 编辑模板 | 名称、说明、**券种**(折扣比例 / 满减)、**优惠比例 1–100%**(折扣比例券:数字 + 滑块,100 即免费)或**减免点数**(满减券:不得超过门槛;新建时“可叠加”默认开)、**使用门槛**(满减券必填)(商品原价达到多少点才可用,留空无门槛)、**可叠加**开关(默认关;开启后可与其他可叠加的券一起用,一单最多 3 张)、适用范围(不限商品 / 指定商品:带搜索的复选列表,可“选中当前列表”)、获取方式(用户领取 / 仅管理员发放 / 共享券码)、有效期(不过期 / 发放后 N 天,默认 30 / 固定日期)、总量与每人上限 | 选“共享券码”时出现券码输入与“生成”按钮;**全站最多使用次数默认 1**,可设到 100000 或留空不限;每人最多使用次数默认 1;共享券码不支持“发放后 N 天” |
| 发券 | 选模板,按用户名/UID 搜索添加,或粘贴 UID 批量添加(最多 100 人) | 有不存在或被禁用的用户则整批拒绝并列出;受总量约束;共享券码模板不可发券 |
| 已发出的券 | 按模板、持有者 UID、状态检索 | 未使用的券可作废(必填原因);已使用的不可作废 |

规则:

- 已发出券(共享券码模板:已有使用记录)后,券种、折扣或减免点数、适用范围、使用门槛、可叠加标记、获取方式与券码**不能再改**(422),总量只能上调、不能低于已发/已用;要改折扣请新建模板并停用旧的。
- 删除模板仅限从未发出过券、从未被使用过券码的;其余只能停用。停用后不可领取,已领未用的券显示“模板已停用”且暂不可用,重新启用即恢复。
- 被限定型模板引用的商品不能删除(409);下架不受限。
- 券码 4–32 位字母或数字,不区分大小写,全站唯一,有使用记录后不可改;不是机密,管理端明文可见。输入无效券码的失败按用户限流(10 分钟 10 次,锁 10 分钟)。

## 红包管理 `/admin/red-packets`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 开放范围 | 红包系统总开关;“允许用户之间发红包”开关;可发送的层级与自定义分组 | 保存带版本,冲突时提示刷新;写入审计(含前后值) |
| 红包规则 | 有效时长(1–168 小时)、手续费开关与比例(1%–50%)、发行额度(用户单个/每日、管理员单个/每日/绝对上限) | 同上;仅持有 `admin.redpacket.config` 可改,其余人只读 |
| 发行 | 受众(所有人/分组/指定用户)× 分配方式;管理员出资不扣个人积分;超管可勾选“铸造” | 带幂等键;成功后显示口令 |
| 记录 | 全部红包,可按状态筛选;展开看领取明细;每条显示输入金额、手续费、面额、进度、退回或销毁额 | 进行中的红包可作废(确认后按出资方式退回或销毁) |

页头“发行红包”右侧有齿轮按钮;设置区为摘要卡 + 齿轮弹窗:系统标签放开关,数据标签放费率与额度,范围标签编辑用户/公开红包的发送范围;弹窗为两列表单,关闭即丢弃未保存修改。保存后本人菜单与用户页立即刷新,其他会话 10 秒内生效。

## 签到设置 `/admin/checkin`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 基础设置 | 总开关;奖励上限(默认 10000) | 上限只有超管可改 |
| 默认规则 | 未命中任何规则的用户使用的奖励区间(默认 1–5)与开关 | 区间需满足 `0 ≤ 最小 ≤ 最大 ≤ 上限` |
| 分组规则 | 列表:适用对象(层级与自定义分组)、是否允许签到、奖励区间 | 新增/编辑/删除;多规则命中时**任一关闭则不能签到,否则取上限最高者** |
| 试算 | 输入用户 UID,显示他当前会命中的规则与区间 | 只读 |

页面标题行右侧有齿轮按钮;设置区为摘要卡 + 齿轮弹窗:系统标签放开关,数据标签放奖励区间与连签奖励,规则标签放分组规则与预览;保存后功能开关在 10 秒内同步到用户导航。

## 积分调整、对账与系统账户 `/admin/points`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 手动调整 | 用户 UID、增减金额、原因(必填);显示本次可调整的上限 | 超额禁用提交;无需复核;必写账本与审计 |
| 系统账户 | 收取红包手续费的内置账户:余额、账本合计、是否一致、最近流水 | 只读 |
| 对账 | 账本合计与余额不一致的用户 | “修复并终结”仅超管,选择以账本或以余额为准并填写原因,写审计 |

## 角色差异

| 能力 | admin | super_admin |
|---|---|---|
| 商品管理、作废、发非积分卡 | 是 | 是 |
| 查看卡号 | 须被超管授权 | 是 |
| 发积分卡 | 否 | 是 |
| 红包发行与作废 | 是 | 是；含铸造 |
| 积分调整 | 有 `admin.points.adjust` 权限 | 是 |
| 对账查看 | 是 | 是 |
| 对账差异终结 | 否 | 是 |

## 状态与边界

- 调整导致余额为负：后端拒绝，提示“余额不足”。
- 商品被同时修改：409。
- 红包被并发领取时作废：以后端结果为准，列表刷新。

## 依赖接口

`/admin/shop/*`(含 `cards/{id}/reveal`、`void`、`issue`、`products/{id}/image`、`gift-cards/logo`)、`/admin/points/red-packets*`(含 `/policy`、`/{id}/claims`、`/{id}/void`)、`/admin/checkin/*`、`/admin/points/adjust*`、`/admin/points/reconcile*`、`/admin/points/system`。
