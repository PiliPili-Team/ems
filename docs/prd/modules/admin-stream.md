# A4 推流节点与线路

<span class="badge-planned">待实现</span> 后端节点、线路、类型 schema、试匹配、探测接口均已实现。

## 概念

- **节点**：一个具体的数据来源或转发目标，有类型和匹配规则。
- **线路**：用户选择的入口，包含按顺序排列的一组节点。
- 两层路由：线路选择（用户可见，可选）× 节点正则匹配（线路内按顺序，用户无感）。

## 节点管理

| 子功能 | 展示 | 交互 |
|---|---|---|
| 节点卡片列表 | 类型徽标、匹配方式与表达式、线路内顺序、启停开关、延迟、远程节点标记 | 开关即时保存；点击编辑 |
| 选择类型 | 六类图标卡：磁盘、OpenList、DirectLink、WebDav、Google Drive、StreamRelay | 选中后进入对应表单 |
| 类型化表单 | **字段由后端 `node-types` schema 驱动**，未加载前显示骨架并禁用 | 密钥类字段显示“已设置”；前端不硬编码字段 |
| 匹配规则 | 匹配方式（regex / prefix / any）+ 表达式输入框 | 前端实时试编译正则；“试匹配”输入样例路径调用后端，显示命中与否（后端为准） |
| 探测 | “探测”按钮 | 显示可达性与延迟 |
| 保存 | — | 热生效提示；失败显示字段级错误 |
| 删除 | 行菜单 | 被线路引用时后端拒绝并列出线路 |

## 线路管理

| 子功能 | 展示 | 交互 |
|---|---|---|
| 线路列表 | 名称、入口地址、接入范围摘要（`全员` / `N 层级 + M 用户`）、主线路星标、节点数、启停 | 开关即时保存 |
| 编辑线路 | 基本信息 + [接入范围编辑器](/modules/admin-media#接入范围编辑器) + 节点选择 | 节点多选；**拖拽排序即优先级** |
| 保存节点顺序 | 独立保存按钮 | 提交完整有序列表 |
| 主线路 | 星标 | 至少需要一条启用的主线路；取消最后一条时拒绝 |
| 延迟面板 | 节点 × 线路延迟矩阵 | 30 秒自动刷新 |

## 角色差异

| 能力 | admin | super_admin |
|---|---|---|
| 查看 | 有 `admin.config.media` | 是 |
| 创建、编辑、删除 | 有对应写权限 | 是 |

普通用户只在 [线路](/modules/lines) 页看到结果，不接触节点。

## 状态与边界

- 正则无效：前端试编译失败时阻止保存。
- 试匹配后端不可用：显示“无法验证”，允许保存但警告。
- 节点类型 schema 加载失败：表单不可用，提供重试。

## 依赖接口

`/admin/stream/nodes*`、`/admin/stream/node-types`、`/admin/stream/nodes/test-pattern`、`/admin/stream/nodes/{id}/probe`、`/admin/stream/lines*`。
