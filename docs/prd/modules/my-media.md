# P3 我的媒体账号

<span class="badge-built">已实现</span> 延迟徽标与播放信息接口后端仍为 planned，实现前卡片不显示延迟。

## 目的

用户在这里管理自己的 Emby 账号：查看连接信息、续期、改密、认领已有账号。这是**到期自救**的核心入口，必须在账号不可用时仍可访问。

## 子功能

| 子功能 | 展示 | 交互 |
|---|---|---|
| 账号卡片 | 服务器名称、地址（可复制）、Emby 用户名、到期日与剩余天数、延迟徽标（30 秒刷新；账号延迟接口后端仍为 planned，实现前不显示） | 复制地址；点击“前往播放” |
| 生命周期徽标 | `正常`（绿）、`已到期`（橙，附剩余宽限天数）、`清除中`（橙）、`已清除`（灰） | 只读 |
| 停用徽标 | 红色“已被管理员停用”，与生命周期徽标并列 | 只读 |
| 续期 | “续期”按钮，弹窗输入续期卡号(走统一兑换 `/shop/redeem`) | 成功后徽标与到期日立即刷新；错误提示（卡号无效、已兑换、已过期、已作废) |
| 修改密码 | 按钮 + 弹窗（新密码、确认） | 账号不可用时按钮置灰，悬停说明“账号已到期，续期后可改密” |
| 开通账号 | 无账号时显示引导卡片：输入开通卡号(走统一兑换)；**所有可开通的用户**在弹窗顶部可切换“直接创建”(默认选中；可切回开通卡)：为自己在当前启用的服务器创建账号，无需卡，Emby 用户名自行填写（3–32 位英文字母或数字，不能全是数字），密码仍由后端随机生成 | 成功后展示连接信息；Emby 初始密码由后端随机生成，**仅在开通成功的弹窗中显示一次**（可复制），不存储、不写日志，关闭后不可再看（可用“修改密码”重置） |
| 认领已有账号 | “认领已有 Emby 账号”入口（功能开启时） | 输入 Emby 用户名与密码；验证后绑定；审批模式显示“待审批”，可查看申请状态（被拒绝时只显示状态，后端不提供拒绝原因） |
| 多服务器 | 标签页切换，每个服务器一张卡 | 切换保留各自状态 |

### 按钮可用性

按钮状态完全读取后端下发的 `capabilities`（续期、改密、认领、开通），前端不推导规则。

| 账号状态 | 续期 | 改密 | 播放入口 | 其他 EMS 功能 |
|---|---|---|---|---|
| 正常 | 可用 | 可用 | 可用 | 可用 |
| 已到期（宽限内） | **可用** | 置灰 | 置灰 | 可用 |
| 停用 | **可用**（不解除停用） | 置灰 | 置灰 | 可用 |
| 已到期且停用 | **可用** | 置灰 | 置灰 | 可用 |
| 已清除 | 不显示 | 不显示 | 不显示 | 显示“重新开通 / 认领”引导 |

页面顶部提示条明确区分两类能力：EMS 侧（续期、线路、积分、商店、求片）可用；Emby 侧（播放、改密、在线设备）不可用，并说明原因。

永久成员（后端 `expiresAt` 为空，即服务器 `keepAlive=false`）不显示续期入口与到期信息。

## 角色差异

| 角色 | 差异 |
|---|---|
| 全部 | 只能看到自己的账号；admin 查看他人账号在“媒体账号管理”中进行 |

## 状态与边界

- 无账号：显示开通与认领两个入口。
- 认领被拒：只显示“已被拒绝”状态，不显示原因（后端无此字段），该服务器可再次提交；待审批的服务器在审批前不能再次提交。
- 延迟探测失败：徽标显示“未知”，不报错弹窗。

## 实现说明

- 开通、认领入口是否出现取 `/auth/me.capabilities`（跨服务器聚合）；账号卡片上的续期、改密取各账号自己的 `capabilities`。账号级的 `claim`、`provision` 恒为假，不能用于判断入口。
- 认领时 Emby 拒绝凭证，后端返回 `401 UNAUTHENTICATED`，与会话失效同码。页面对该接口跳过统一登出，再用一次 `/auth/me` 区分：会话有效则提示“Emby 用户名或密码错误”，会话失效则由统一流程登出。
- 普通用户直接创建调用 `POST /media/accounts/direct`，管理员为自己或为他人创建调用 `POST /admin/users/{id}/media-accounts`；同名 Emby 用户、已有账号、服务器未启用分别提示 409 的三种原因，不依赖卡。
- 开通卡、续期卡由商店购买或管理员发卡获得;`POST /media/accounts` 与续期接口不再接收卡号,统一走 `POST /shop/redeem`。开通卡的用户名由系统生成,初始密码仅显示一次。

## 依赖接口

`/media/servers`、`/media/accounts`（含 renew、password、claim）、`/media/claims`、`/media/accounts/{id}/latency`（planned）、`/media/playback-info`（planned）。
