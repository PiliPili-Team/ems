# P9 个人资料与安全

<span class="badge-built">已实现</span> 外观设置已有独立的自定义项；Telegram 绑定支持生成一次性码、深链；一个账号只绑定一个 Telegram 账号，解绑须由已绑定的 Telegram 账号发送解绑码确认。

## 子功能

| 区块 | 展示 | 交互 |
|---|---|---|
| 资料 | 头像、用户名（只读）、角色与层级标签 | 上传头像：PNG / JPEG / WebP，≤ 2 MB，成功后即时更新；可移除 |
| 密码 | 旧密码、新密码、确认 | 成功后其他设备退出;本页自动用新密码重新登录并刷新,失败则提示“密码已修改，请重新登录”并跳登录页,登录后回到原页 |
| 通行密钥 | 已注册列表（名称、创建时间） | 添加（调起 WebAuthn）；删除需确认 |
| 登录会话 | 当前与其他设备列表（设备、IP、最近活动） | 可撤销其他会话；当前会话标记“本设备” |
| Telegram 绑定 | 已绑定账号列表（显示名、绑定时间） | “生成绑定码”显示 10 分钟一次性码、剩余秒数、Bot 深链与 `/bind <code>` 复制按钮；显示期间每 3 秒读取绑定列表，成功后自动收起。已绑定时不再提供绑定入口，「解绑」生成 10 分钟一次性解绑码与 `/unbind <code>`，须由已绑定的 Telegram 账号私聊 Bot 发送；面板内「无法使用原 Telegram 账户？」打开免费的「Telegram 解绑申请」工单 |
| 外观 | 主题（浅 / 深 / 跟随系统）、主题风格、布局与圆角、透明度预设 | 实时预览；保存后跨设备同步；失败保留预览并提示 |
| 语言 | 简体中文、English | 立即切换并保存 |
| 当前线路 | 显示所选线路 | 跳转 [线路](/modules/lines) |

## 角色差异

| 角色 | 差异 |
|---|---|
| 全部 | 只能编辑自己的资料 |
| super_admin | 额外显示当前 API Key 前缀入口（跳转超管专区） |

## 状态与边界

- 旧密码错误：字段内联错误；限流时显示等待时间。
- 外观并发保存：版本冲突时提示并重新拉取。
- 会话被撤销后：下一次请求跳转登录。
- Telegram 未启用（没有主 Bot）：只显示“管理员尚未启用 Telegram”，不显示生成按钮。
- 绑定码过期：提示重新生成；限流：显示等待秒数并暂时禁用按钮。
- 解绑：只能由已绑定的 Telegram 账号发送解绑码完成，其他账号发送无效且解绑码保持有效；解绑后该 Telegram 账号不能再登录或打开 Mini App，但**不撤销既有会话**。
- 原账号无法使用：提交「Telegram 解绑申请」工单（免提交费，附说明与证明），管理员在用户详情「强制解绑 Telegram」（需 `admin.users.update`，超级管理员可对任何人，管理员仅对普通用户；填写原因、写审计、站内通知用户）。

## 依赖接口

`/auth/me`、`PATCH /auth/password`、`/me/profile`、`/me/avatar`、`/me/passkeys`、`/me/sessions`、`/me/telegram/*`、`DELETE /me/telegram/bindings/{id}`、`/me/appearance`。
