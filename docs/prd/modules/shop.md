# P6 我的商店与卡券中心

<span class="badge-built">已实现</span> 我的商店、卡券中心与统一兑换均已实现。

「卡券中心」是所有卡券的统一入口,按种类分标签:**礼品卡**与**优惠券**,新增一种卡券只需登记一个种类,不新增菜单。

礼品卡类似 App Store 礼品卡:买到卡号,**持有者**可以自己兑换或赠送,由**兑换者**使用。每张卡记录持有者、兑换者与兑换时间。**邀请卡**只在注册时使用,持有者成为新账号的邀请人;个人终身购买数及可邀请人数受 `registration.inviteLimit`(1–20) 约束。

商品类型(SKU):积分卡(面值积分)、VIP 卡、白名单卡、开通卡、续期卡、邀请卡,以及**心愿点数**。心愿点数不是礼品卡:面值 N 的价格必须为 N 普通积分,库存不限,购买后即时把 N 点计入购买人的已购心愿点数余额并记账,不发卡,不支持优惠券。积分关闭或积分不足时不发生扣款与入账。


## 我的商店 `/shop`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 商品卡片 | 与商品管理同一张卡：图片区（未上传时按卡种着色的默认图案）、名称、面值(“VIP 30 天”“永久”)、有效期规则(“卡不过期”“购买后 30 天内兑换”“截止到某日”)、库存、价格 | 点击“购买” |
| 不可购买 | 按钮置灰并给出原因(无可得、服务器不可用、库存耗尽等) | 前端只展示后端给出的原因 |
| 购买确认 | 弹窗:商品、价格、当前余额、购买后余额、兑换截止;支持优惠券的礼品卡另有“优惠券”区(见下) | 确认后扣分;礼品卡成功展示可复制的卡号,心愿点数商品成功直接更新余额 |
| 订单记录 | 商品、实付、时间、关联卡;用过优惠券的显示“原价 X,优惠 Y” | 分页 |
| 兑换礼品卡 | 页头按钮,与页面标题同排;输入卡号 | 与“我的礼品卡”同一个对话框 |

购买请求带幂等键,重复点击不会重复扣分。积分卡的积分来自系统账户:购买款进系统账户,兑换时由系统账户划给兑换者,**与用户之间的积分转赠开关、转赠限制无关**(转赠关闭时积分卡照常可买可兑)。最低售价按红包手续费规则反推,使买卖不会凭空造分。

### 购买时使用优惠券

购买对话框(积分卡和心愿点数商品除外:积分卡最低价按红包手续费反推,心愿点数须保持 1:1 原价)多一个“优惠券”区:

- 默认“不使用优惠券”;下面列出我持有的未使用券,每张显示“可叠加 / 不可叠加”与使用门槛,可用的显示单独使用的实付,不可用的置灰并显示原因(不在适用范围、未达使用门槛、已过期、模板已停用、优惠为 0 等)。
- **叠加**:券分两种:**百分比券**(减 N%)与**满减券**(满 T 减 M)。标了“可叠加”的券可以组合,但**同类券不能同时使用**(10% 与 20% 不能一起用),所以一单最多 2 张:一张百分比券加一张满减券(共享券码按它所属的券种算一张)。选另一张同类券会替换已选的同类券;选一张不可叠加的券会清掉其他选择,已选不可叠加的券时其余券置灰。实付 = max(0, ⌈原价 × (100 − 百分比) / 100⌉ − 满减额):先算百分比再减满减额,只取整一次,最低为 0,不会为负(例:原价 300,50% 券 + 满 200 减 20 券,实付 130)。每次选择变化,价格区以服务器的组合预览为准;组合被拒绝时显示原因(不可叠加、同类券不可叠加、超过张数、未达门槛等)并禁用确认。
- **门槛**:券可设“原价 ≥ N 点才可用”,每张券各自按原价判断,与叠加后的中间价无关;满减券的门槛必填。
- “输入券码”:共享券码(见管理端)输入后点“验证”,验证通过后作为组合的一员参与预览(可叠加的券码可与可叠加的券一起用,不可叠加的券码只能单独用)。验证不消耗次数;连续输错 10 次锁定 10 分钟。
- 价格区显示原价(划线)、优惠、实付,“购买后余额”按实付计算;100% 的券实付 0,余额为 0 也能买。
- 实付 = ⌈原价 × (100 − 折扣) / 100⌉。折扣只改变实付,不产生账本分录:系统账户只收实付款,总量守恒。作废并退款只退实付,券与券码次数不返还。

## 卡券中心 `/vouchers`

旧地址 `/shop/cards` 自动跳转到这里。页面按卡券种类分标签:“礼品卡”“优惠券”;当前种类的操作位于页头,与标题同排。

| 子功能 | 展示 | 交互 |
|---|---|---|
| 卡列表 | App Store 风格卡面:按卡种着色的渐变、运营方 LOGO(未上传时为内置图标)、面值、编号、状态(未兑换 / 已兑换 / 已作废 / 已过期)、有效期或兑换信息 | 按类型与状态筛选;点击卡面打开详情 |
| 卡号 | 默认遮罩 | 点击显示并复制;仅持有者可见 |
| 兑换信息 | 兑换者用户名与时间(已兑换时);“被管理员查看过 N 次” | 只读 |
| 立即兑换 | 开通卡无需输入用户名(系统生成),续期卡选择账号 | 成功后显示结果(余额、层级与到期时间、开通卡的一次性初始密码)并刷新会话 |

### 优惠券标签

| 子功能 | 展示 | 交互 |
|---|---|---|
| 可领取 | 券面(“减 20%”“免费”)、适用范围(全部商品 / 指定 N 个)、剩余数量;已领满、已领完、商店关闭时置灰并说明 | 点击“领取”(带幂等键);成功后“我的优惠券”立即出现 |
| 我的优惠券 | 券面、适用范围、有效期、状态(未使用 / 已使用 / 已过期 / 已作废);模板被停用时提示“这类优惠券已停用” | 按状态筛选;已使用的显示所用订单 |

共享券码不会出现在这里(它们不是领取的券,只在购买时输入)。

## 状态与边界

- 商店关闭:只停止购买,已持有的卡仍可查看与兑换;菜单“我的商店”隐藏,“卡券中心”仍在(持有卡时)。
- 兑换失败时卡保持未兑换;基础层级已不低于卡的层级时不烧卡。
- 兑换按用户限流:10 分钟内失败 10 次返回 429。
- 商品下架:下单返回冲突,列表刷新。
- 商店或积分关闭:不能领取优惠券、不能用券或券码购买;已持有的券仍可查看。
