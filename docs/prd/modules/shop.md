## 商店 `/shop`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 商品卡片 | 图标、名称、价格、有效期说明（“30 天”“永久”）、库存（无限不显示） | 点击“兑换” |
| 可见性 | 由后端过滤：保号模式不出续期码；已是 VIP 不出 VIP 码等 | 前端不二次过滤 |
| 兑换确认 | 弹窗：商品、价格、当前余额、兑换后余额 | 确认后扣分；成功展示码并提供复制 |
| 余额不足 | 按钮置灰，提示差额，附“去赚积分”入口 | 跳转 `/points` |
| 订单记录 | 列表：商品、价格、时间、关联码 | 分页 |

兑换请求带幂等键，重复点击不会重复扣分。

## 我的码 `/shop/codes`

码有五类：**注册码、续期码、邀请码、VIP 码、白名单码**。

| 子功能 | 展示 | 交互 |
|---|---|---|
| 码列表 | 类型、状态（未使用 / 已使用 / 已作废）、获得时间 | 按类型与状态筛选 |
| 使用注册码 | “一键开通”按钮 | 进入[开通账号流程](/modules/my-media) |
| 使用续期码 | “去续期”按钮 | 跳转 `/my-media` 并预填 |
| 使用 VIP / 白名单码 | “立即使用”按钮 | 确认后升级层级；成功后菜单与线路可见性刷新 |
| 邀请码 | 展示码字符串与说明 | 复制分享；显示被谁使用 |
| 码详情 | 溯源时间线：兑换、使用、作废 | 只读 |

## 角色差异

| 角色 | 差异 |
|---|---|
| user | 全部个人功能 |
| admin / super_admin | 个人功能同用户；商品与码管理见 [商店、红包与积分运营](/modules/admin-commerce) |

## 状态与边界

- 商品被下架：兑换返回冲突，列表刷新。
- 库存耗尽：卡片显示“已售罄”。
- 层级码低于当前层级：**不降级**，后端拒绝并说明。

## 依赖接口

`/shop/products`、`/shop/orders`、`/shop/codes`、`/shop/codes/{id}`、`/shop/codes/{id}/use`。
