# P6 商店与我的礼品卡

<span class="badge-built">已实现</span> 商店、我的礼品卡与统一兑换均已实现。

商店卖的是**礼品卡**,类似 App Store 礼品卡:买到的是一串卡号,**持有者**可以自己兑换,也可以把卡号送给别人,由**兑换者**使用。每张卡记录持有者、兑换者、兑换时间。本期不含邀请码。

卡的类型(SKU):**积分卡**(面值为积分)、**VIP 卡**(天数,0 为永久)、**白名单卡**(天数,0 为永久)、**开通卡**(为兑换者开通媒体账号)、**续期卡**(为兑换者的媒体账号续期)。

## 商店 `/shop`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 商品卡片 | 图标、名称、面值(“VIP 30 天”“永久”)、有效期规则(“卡不过期”“购买后 30 天内兑换”“截止到某日”)、价格 | 点击“购买” |
| 不可购买 | 按钮置灰并给出原因(无可得、服务器不可用、积分转赠未开放、库存耗尽等) | 前端只展示后端给出的原因 |
| 购买确认 | 弹窗:商品、价格、当前余额、购买后余额、兑换截止 | 确认后扣分;成功展示卡号并提供复制 |
| 订单记录 | 商品、价格、时间、关联卡 | 分页 |
| 兑换礼品卡 | 页头按钮,输入卡号 | 与“我的礼品卡”同一个对话框 |

购买请求带幂等键,重复点击不会重复扣分。积分卡的最低售价按红包手续费规则反推,使买卖不会凭空造分。

## 我的礼品卡 `/shop/cards`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 卡列表 | 类型与面值、状态(未兑换 / 已兑换 / 已作废 / 已过期)、有效期 | 按类型与状态筛选 |
| 卡号 | 默认遮罩 | 点击显示并复制;仅持有者可见 |
| 兑换信息 | 兑换者用户名与时间(已兑换时);“被管理员查看过 N 次” | 只读 |
| 立即兑换 | 开通卡无需输入用户名(系统生成),续期卡选择账号 | 成功后显示结果(余额、层级与到期时间、开通卡的一次性初始密码)并刷新会话 |

## 角色差异

| 角色 | 差异 |
|---|---|
| user | 全部个人功能;已无可得的类型显示“无可得”,兑换也会被拒且不烧卡 |
| admin / super_admin | 个人功能同用户;商品与礼品卡管理见 [商店、红包与积分运营](/modules/admin-commerce) |

## 状态与边界

- 商店关闭:只停止购买,已持有的卡仍可查看与兑换;菜单“商店”隐藏,“我的礼品卡”仍在(持有卡时)。
- 兑换失败时卡保持未兑换;基础层级已不低于卡的层级时不烧卡。
- 兑换按用户限流:10 分钟内失败 10 次返回 429。
- 商品下架:下单返回冲突,列表刷新。

## 依赖接口

`/shop/products`、`/shop/orders`、`/shop/cards`、`/shop/cards/{id}`、`/shop/redeem`。
