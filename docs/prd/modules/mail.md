# P13 我的邮件

<span class="badge-built">已实现</span> 站点以「系统」名义给用户发送邮件,邮件可带附件,收件人在邮件内领取。铃铛通知中心只负责提醒,邮件本身在独立的 `/mail` 页面阅读与领取。

## 我的邮件 `/mail`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 摘要列表 | 发件方(系统)、标题、日期、未读圆点、附件类型图标;待领取的邮件显示到期提示,3 天内到期用警告色;已领、已过期、已撤回的显示状态 | 点击打开;分页 |
| 详情 | 标题、发件方与时间、受限 Markdown 正文(无 HTML、无图片)、附件格子(图标、数量、类型) | 打开即标记已读;「领取」一次领完整封邮件的附件,成功后附件格子翻面显示「已领取」(减少动效时直接切换) |
| 一键领取 | 页头按钮显示可领封数 | 逐封独立领取,结果弹窗依次列出领到的物品与未能领取的邮件及原因;失败的邮件保留可再领 |
| 删除 | 没有待领附件时显示 | 确认后从列表移除;仍有待领附件的邮件不能删除(409) |

没有邮件时只显示「还没有邮件」,不显示说明文字、右栏与「选择一封邮件查看」。桌面(`lg` 起)为左栏摘要、右栏详情;更窄时为两级页面:列表在 `/mail`,单封在 `/mail/:id`(顶栏返回)。铃铛通知链接 `/mail?id=N` 会跳到 `/mail/N`。不在侧栏与应用中心出现,入口是个人中心 `/profile` 横幅右侧的信封图标:有未读时右上角显示小红点,鼠标悬停或键盘聚焦时信封摇动一下(减少动效时不动),新邮件通知到达时实时更新。附件类型为当前页面不认识的数值时,提示刷新页面且不可领取。

**附件类型**(数值枚举):1 积分、2 补签卡、3 超级补签卡、4 礼物(目标为礼物目录,按数量发放第一个款式,藏品分配新编号)、5 优惠券(模板)、6 兑换码(礼品卡商品)。

**领取规则**:每位收件人每封邮件的附件只领一次,发放与记录在同一事务;积分由系统账户(编号 0)先生成再支付,账本来源「邮件附件」25,显示为系统;补签卡来源为「邮件」;优惠券按模板规则发放(模板关闭、售罄或过期则该封领取失败);积分类兑换码在发放时于系统账户生成面值。邮件到期(默认发送后 30 天)后未领附件作废,邮件再保留 30 天后自动清理。

## 邮件管理 `/admin/mail`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 已发邮件 | 自动填充卡片:标题、编号与时间、收件范围、附件、收件人 / 已读 / 已领取统计;投递中、已撤回、已过期徽标 | 「撤回」(确认后作废未领附件,已领的不收回) |
| 撰写 | 右侧抽屉:标题、正文(编辑 / 预览)、附件行(类型下拉、模板或商品下拉、数量)、收件人(指定用户 / 层级与分组 / 全体)、有效期 | 实时显示将送达人数;超出每人积分上限或单次收件人上限时提示并禁止发送;发送前确认 |
| 邮件限制 | 齿轮打开右侧抽屉:每人积分上限(默认 10000)、单次收件人上限(默认 5000)、默认有效期(默认 30 天) | 只有超管能保存;其他管理员看到禁用的值 |

指定用户用搜索 + 分页 + 勾选批量添加,已选名单分页显示,最多 1000 人;层级与分组在发送时刻求值,之后加入的用户收不到。群发分批投递,中断后由计划任务 `mail.sweep`(每 10 分钟)续投并清理过期邮件。积分类兑换码只有超管能发;超管不受每人积分上限限制。发送、领取、撤回与修改限制都写审计(模块「邮件」)。

权限:`mail.self`(所有用户)、`admin.mail.read`(管理员默认)、`admin.mail.write`(可授予,高风险)。
