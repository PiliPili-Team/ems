# A6 系统设置与审计

系统设置、插件、宿主机文件、服务状态 <span class="badge-built">已实现</span>；审计日志页与 OpenAPI 页 <span class="badge-built">已实现</span>。

## 系统设置 `/setting`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 配置域导航 | 左侧：通用、网关、积分、商店、求片、注册、外观、通知等（由后端 manifest 决定） | 切换时若有未保存修改，提示确认 |
| 配置表单 | 右侧按配置域渲染 | 保存前显示**差异预览**；成功提示；冲突（409）提示刷新 |
| 密钥字段 | 显示“已设置” | 明确的“替换”或“清除”，不回显 |
| 热生效等级 | 字段旁标记“即时生效 / 需重启” | 只读标记 |
| 版本历史 | 仅超管显示 | 查看某域的历史版本 |
| 引导级配置 | 数据库、Redis、监听、密钥**不在此页** | 超管在 [引导配置](/modules/super) 只读查看 |

## 服务状态与日志 `/service-status`（管理员视图）

| 子功能 | 展示 | 交互 |
|---|---|---|
| 系统状态 | 进程、平台、依赖健康 | 自动刷新 |
| 实时日志 | 滚动日志流，带级别着色 | 先换取一次性票据再连接；暂停、清屏、级别过滤、关键字过滤；敏感信息已由后端脱敏 |
| 历史日志 | 日志文件列表 | 下载 |
| 任务队列 | 异步任务（outbox）列表：状态、重试次数、错误 | 失败任务可“重放”（需 `admin.scheduler.write`） |

## 插件 `/plugins`

仅展示受信任的内置插件，不支持远程市场与安装。

| 展示 | 交互 |
|---|---|
| 插件卡片与启用状态 | 启用 / 停用；打开插件提供的管理入口 |

## 宿主机文件 `/filemanager`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 文件浏览 | 面包屑 + 列表（名称、大小、修改时间） | 进入目录、下载文件 |
| 新建文件夹、重命名、删除 | 仅超管显示按钮 | 删除永久；非空目录需勾选递归并**输入完整名称**确认 |
| 受保护路径 | 隐藏的（数据目录、日志目录）不出现；系统目录只读并带锁图标 | 写操作被拒时提示原因 |
| 操作系统拒绝 | 说明如何授权（Docker 挂载、macOS 完整磁盘访问、Windows 账号权限） | 只读说明 |

写操作在执行前先写入审计日志。

## 审计日志 `/admin/audit`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 日志列表 | 时间、操作人、动作、对象、结果、来源 IP | 按操作人、动作、时间范围、结果筛选；分页 |
| 详情 | 展开显示脱敏后的上下文 | 只读 |

## OpenAPI `/openapi`

内置文档页，仅 admin 及以上可见，不含任何密钥。前端以当前会话读取 `/openapi.json`,用 Swagger UI 渲染(随主题明暗切换),桌面与窄屏均可阅读。

## 角色差异

| 能力 | admin | super_admin |
|---|---|---|
| 设置读写 | 按配置域权限 | 全部，含版本历史 |
| 日志、状态 | 查看 | 查看 |
| 宿主机文件 | 浏览、下载 | 全部写操作 |
| 审计日志 | 查看 | 查看 |
| OpenAPI | 查看 | 查看 |

## 依赖接口

`/admin/config*`、`/admin/system*`、`/admin/outbox/jobs*`、`/admin/plugins`、`/admin/files`、`/admin/audit-logs`、`/openapi.json`。
