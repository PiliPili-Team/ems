# P2 首页与应用中心

<span class="badge-built">应用中心已实现</span> <span class="badge-planned">用户首页概览待实现</span> 运营仪表盘（管理员）已实现，见下文。

## 设计结论

| 页面 | 路由 | 受众 | 内容边界 |
|---|---|---|---|
| **首页 / 应用中心** | `/apps`（沿用现有路径） | 全部登录角色 | 只含个人数据与**聚合、非敏感**的统计 |
| **运营仪表盘** | `/dashboard` | admin 及以上 | 系统指标、他人的实时播放与设备信息等敏感内容 |

登录后默认进入首页。管理员可从菜单进入运营仪表盘。

## 首页 `/apps`

| 区块 | 展示 | 交互 |
|---|---|---|
| 我的状态 | 媒体账号状态与到期倒计时（保号模式隐藏）、层级徽标、积分余额（积分功能开启时） | 点击进入 [我的媒体](/modules/my-media) 或 [积分中心](/modules/points)；账号临近到期（后端阈值）时显示橙色提示与“去续期”按钮 |
| 快捷操作 | “今日签到”按钮（积分开启时）；“求片”入口 | 点击签到直接完成并更新余额；已签到置灰 |
| 功能入口 | 当前账号已启用功能的卡片（发现、求片、积分、红包、商店、线路等） | 点击进入；层级不足的功能显示锁定态与升级说明 |
| 在线人数 | 聚合数字 | 只读 |
| 今日 / 7 日 Top5 | 电影、剧集标签切换，海报卡片 | 点击在新窗口打开 TMDB |
| 最近入库 | 横向滚动海报列表 | 滚动到末尾加载下一页 |
| 版本信息 | 页脚版本号 | 只读 |

**不出现**：他人的用户名、实时播放明细、设备信息、系统与网络指标、日志。

区块是否显示由权限点与 `/app/features` 决定；某个区块失败只影响自身，显示重试。

## 运营仪表盘 `/dashboard`（admin 及以上，只读）

| 子功能 | 展示 | 交互 |
|---|---|---|
| 系统概况 | 进程状态、平台信息、存储指标卡片 | 自动刷新；点击进入服务状态 |
| 用户卡片 | 用户数量与状态分布 | 点击进入用户管理 |
| 网络指标 | 吞吐与连接指标 | 只读 |
| 实时播放 | 表格：用户、媒体、码率、客户端、线路 | WebSocket 推送；断线自动重连并显示“已断开” |
| 设备统计 | 设备类型分布、活跃设备 TopN | 只读 |

实时播放需要一次性票据换取连接，票据过期自动重新获取。

## 角色差异

| 角色 | 首页 | 运营仪表盘 |
|---|---|---|
| user（任一层级） | 全部区块；功能入口按层级与开关过滤 | 不可见 |
| admin / super_admin | 同用户 | 仅查看 |

## 状态与边界

- 没有媒体账号：“我的状态”显示开通 / 认领引导，不显示到期倒计时。
- 积分功能关闭：余额与签到隐藏。
- 刚部署无数据：Top5 与最近入库显示“暂无数据”，不显示 0。
- 某指标接口失败：该区块显示错误与重试。

## 依赖接口

`/app/features`、`/app/version`、`/auth/me`、`/media/accounts`、`/points/balance`、`/stats/*`；仪表盘另用 `/admin/system`、`/admin/streams` 与票据接口、`/admin/device-stats`（planned）。
