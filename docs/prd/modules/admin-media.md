# A3 媒体服务器与媒体账号

<span class="badge-built">部分实现</span> 媒体服务器页 `/admin/media-servers` 已实现(列表、新建/编辑、测试连接、启用切换);媒体库接入范围、认领配置与审批、媒体账号管理页待实现。

## 媒体服务器 `/admin/media-servers`

**唯一启用**：可以添加多个服务器，但同一时刻只启用一个；系统中的第一台服务器添加后自动启用（后端保证，表单中的开关显示为开启并锁定），之后添加的服务器默认不启用；启用某个服务器会在同一事务内停用其余服务器。服务器编号是自增整数，账号、认领都绑定到具体的服务器编号。切换后用户只看到当前启用服务器上的账号，在新服务器上还没有账号的用户看不到旧账号；旧服务器上的账号与认领被保留，切回后重新可见，其到期与清除在未启用期间冻结。停用唯一启用的服务器后，用户侧显示“暂无可用服务器”。

| 子功能 | 展示 | 交互 |
|---|---|---|
| 服务器列表 | 显示名、地址、连通状态、媒体库数量 | 点击进入详情 |
| 新建 / 编辑 | 表单：地址、API Key、显示名、账期，以及**新账号默认策略**：最大同时播放数（缺省 3，0 不限）与 Emby 管理员权限（缺省关） | API Key 只显示“已设置”，操作为“替换”；“测试连接”即时反馈；默认策略只影响之后创建的账号 |
| 媒体库接入范围 | 媒体库列表；每个库显示层级勾选与分组数 | 点击打开[接入范围编辑器](#接入范围编辑器)；保存后经队列异步生效，显示“同步中” |
| 认领配置 | 认领开关、是否需要审批 | 保存带版本 |
| 认领审批 | 申请列表：待审优先，含历史决策与拒绝原因 | 通过 / 拒绝（拒绝需填原因）；结果通知申请人 |

### 接入范围编辑器

媒体库与线路共用同一个编辑器。

| 元素 | 说明 |
|---|---|
| 模式 | 单选：**不限**（全员）或 **受限** |
| 受限：层级 | 多选芯片：normal / vip / whitelist |
| 受限：自定义分组 | 从全局分组多选,显示别名、`#编号` 与成员数;不提供逐个 UID 输入(见 [A8 访问分组](/modules/admin-groups)) |
| 规则 | 命中任一条件即放行（any-of） |
| 预览 | 显示“当前影响 N 名用户”(所选层级中的活跃用户与分组成员取并集、去重,排除已禁用) |

## 媒体账号管理 `/admin/media-accounts`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 账号列表 | 用户、Emby 用户名、生命周期徽标、停用徽标、到期日、宽限剩余 | 按服务器、生命周期、停用状态、关键词筛选；分页 |
| 停用 / 恢复 | 行操作 | 确认文案强调“仅停用 Emby 播放，不影响该用户登录与 Bot”；失败时提示“已加入重试队列” |
| 批量停用 | 勾选多行后顶部出现批量操作条 | 确认弹窗显示选中数量；逐行返回结果，失败项单独列出 |
| 重置媒体密码 | 行菜单 | 需要 `admin.media.write` |
| 创建媒体账号 | 接口 `POST /admin/users/{id}/media-accounts`（任意管理员；目标为自己或普通用户）；机器人场景由用户提供用户名 | 用户名 3–32 位英文字母或数字，不能全是数字；初始密码随机，仅在响应中出现一次；他人建号的界面随用户管理页另行提案 |

列表**不展示超级管理员名下的账号**。

## 角色差异

| 能力 | admin | super_admin |
|---|---|---|
| 服务器配置 | 有 `admin.config.media` | 是 |
| 库范围编辑 | 有 `admin.libraries.write` | 是 |
| 认领审批 | 有 `admin.media.claim_review` | 是 |
| 账号停用 / 恢复 | 有 `admin.media.write` | 是 |

## 状态与边界

- 服务器不可达：测试失败显示具体原因；列表显示“离线”。
- 删除正被使用的服务器：后端拒绝并说明依赖。
- 删除服务器是**软删除**：记录保留供审计,编号不再复用;默认不显示,列表底部“显示已删除的服务器”可只读查看。
- 媒体库规则按“服务器 + Emby 库 ID”保存,EMS 不为库另建编号。库在 Emby 中消失后,规则保留并在库权限对话框中标记“已不存在”,可手动移除;保存其他库的规则时它不会被清除。
- 库权限对话框每个库一行:三个层级勾选 + 分组按钮(三个层级都勾选即对所有人开放,分组不起作用)。
- 范围保存中服务重启：队列任务可在系统页查看与重放。

## 依赖接口

`/admin/media-servers*`、`/admin/media-accounts*`、`/admin/users/{id}/media-accounts`、`/admin/media-servers/{id}/claims*`、`/admin/outbox/jobs*`。

## 新账号默认策略

注册码开通与直接创建在 Emby 创建用户后，先写入一份默认策略，再设置资料库与启用状态（认领的是已有账号，不改其策略）：隐藏用户；允许远程访问与播放；不允许音视频转码、远程控制其他用户、Live TV、删除或下载内容、字幕下载与管理、同步转码、媒体转换、公共分享、相机上传；`SimultaneousStreamLimit` 与 `IsAdministrator` 取自服务器设置。`EnabledFolders` 缺省为全部媒体库，再按资料库规则（用户等级与身份）收窄。Emby 返回的其他策略键原样保留。

认领开关缺省开启。
