# A7 超级管理员专区

<span class="badge-built">已实现</span> 管理员、API Key、引导配置三个页面均已实现；管理员页含单项授权开关。对 admin **完全不可见**，直接访问返回 403。

## 管理员管理 `/super/admins`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 管理员列表 | UID、用户名、创建时间、状态；超管带“超管”标记 | 分页只读列表 |
| 新增管理员 | “新增管理员”按钮；输入**已有账号的完整用户名**,将其提升为管理员 | 账号不存在、已是管理员时给出对应提示;提升后其会话立即清理 |
| 可查看礼品卡号 | 每个管理员一行开关(超管行不显示) | 即时保存,失败回滚;收回立即生效;写审计。admin 默认**不能**查看他人礼品卡号,须由超管授权 |
| 重置密码 | 行内按钮(超管行不显示) | 输入新密码,不回显 |
| 移除管理员 | 行内按钮(超管行不显示) | 确认弹窗,降为普通用户;**不能移除自己**,当前登录者那一行不显示移除按钮 |

## API Key `/super/api-keys`

| 子功能 | 展示 | 交互 |
|---|---|---|
| Key 列表 | 数字编号、前缀、备注、权限数量、创建时间、最近使用 | 分页只读 |
| 创建 | 备注 + 权限范围(多选,至少一项,列表取自后端 OpenAPI 的权限枚举,**不含 `super.*`**) | 创建后**一次性明文**，复制按钮 + “我已保存”勾选才能关闭 |
| 轮换 | 行内按钮 | 二次确认；新明文同样仅显示一次；旧 Key 立即失效;失败时旧 Key 仍有效并提示重试 |
| 吊销 | 行内按钮 | 确认；立即失效 |

API Key 无法用于宿主机文件管理等会话专属接口。

## 引导配置 `/super/bootstrap`

| 展示 | 交互 |
|---|---|
| 存储引擎、数据库路径、监听地址(后端实际返回的三项) | 只读；说明这些值来自环境变量，在此不可修改 |

## 其他仅超管能力（分散在各模块）

链式封禁与回滚、对账差异终结、改角色、宿主机文件写操作、配置版本历史、红包铸造、发积分卡、授予管理员“查看礼品卡号”。入口已在对应模块页标注。

## 状态与边界

- 对 admin：菜单隐藏，直接访问 403。
- 轮换失败：旧 Key 仍有效，提示重试。
- 超管数量：不可通过 UI 增删超管。
