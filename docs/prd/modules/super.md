# A7 超级管理员专区

<span class="badge-planned">待实现</span> 后端接口已实现。对 admin **完全不可见**，直接访问返回 403。

## 管理员管理 `/super/admins`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 管理员列表 | 用户名、创建时间、状态 | 只读列表 |
| 新增管理员 | “新增”按钮；输入用户名与初始密码 | 创建成功提示 |
| 重置密码 | 行菜单 | 输入新密码 |
| 移除管理员 | 行菜单 | 确认弹窗；**不能移除自己**，该行不显示移除按钮 |

## API Key `/super/api-keys`

| 子功能 | 展示 | 交互 |
|---|---|---|
| Key 列表 | 前缀、备注、创建时间、最近使用、状态 | 只读 |
| 创建 | 备注输入 | 创建后**一次性明文**，复制按钮 + “我已保存”勾选才能关闭 |
| 轮换 | 行菜单 | 二次确认；新明文同样仅显示一次；旧 Key 立即失效 |
| 吊销 | 行菜单 | 确认；立即失效 |

API Key 无法用于宿主机文件管理等会话专属接口。

## 引导配置 `/super/bootstrap`

| 展示 | 交互 |
|---|---|
| 数据库、Redis、监听地址、密钥路径等引导级配置，敏感值脱敏 | 只读；说明这些值来自环境变量，在此不可修改 |

## 其他仅超管能力（分散在各模块）

链式封禁与回滚、对账差异终结、改角色、宿主机文件写操作、配置版本历史、红包铸造。入口已在对应模块页标注。

## 状态与边界

- 对 admin：菜单隐藏，直接访问 403。
- 轮换失败：旧 Key 仍有效，提示重试。
- 超管数量：不可通过 UI 增删超管。
