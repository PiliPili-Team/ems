# A1 用户管理与邀请树

用户管理、邀请树与剪枝 <span class="badge-built">已实现</span>：查看（邀请树）与处置（剪枝、回滚）同一阶段交付，避免出现只能看不能处置或相反的半成品。运营仪表盘见 [P2](/modules/home-dashboard)。

## 用户管理 `/user`

| 子功能 | 展示 | 交互 |
|---|---|---|
| 用户列表 | 表格：头像与用户名、角色、层级、积分、媒体账号数、邀请人、状态、注册时间 | 服务端分页；按角色、层级、状态、关键词筛选；列排序 |
| 详情抽屉 | 资料、邀请树位置、账本摘要、媒体账号、审计摘要 | 点击行打开；标签页切换 |
| 禁用 / 恢复 | 状态开关 | 确认弹窗说明连带效果：会话撤销、Bot 拒绝、Emby 连带禁用 |
| 重置密码 | 行菜单“重置密码” | 输入新密码并确认 |
| 修改资料与层级 | 编辑表单 | 提交带 `expectedVersion`；冲突提示刷新 |
| 删除（软删） | 行菜单“删除” | 红色确认，需输入用户名 |
| 重置媒体账号密码 | 抽屉内按钮 | 需 `admin.media.write` |
| 角色管理 | 抽屉内“设为管理员 / 取消管理员” | 仅超管可见 |

**边界规则的展示**：

- admin 的列表中**不出现超级管理员**；查询超管返回 404 风格的“不存在”。
- admin 对管理员的行不显示写操作。
- 任何人对自己的行不显示禁用、删除、改角色。

## 邀请树 `/admin/users/:uid/tree` <span class="badge-built">已实现</span>

入口:用户卡片的“邀请树”(任何能读用户的管理员),页面是“用户”页的子页面(不单独成标签)。

| 子功能 | 展示 | 交互 |
|---|---|---|
| 名片 | 头像、用户名、UID、角色、层级、状态 | 只读 |
| 祖先链 | 从最上层邀请人到该用户的面包屑 | 点击跳转到对应用户的树 |
| 后代树 | 可折叠树形列表,节点显示头像、用户名、角色/已停用/已删除徽标与被邀请人数;前两层默认展开 | 展开/折叠;点用户名进入他的树 |
| 统计 | 后代总数、已停用数 | 只读 |
| 截断 | 后代超过 5000 时提示“只显示了一部分” | 从子节点继续看 |

admin 看不到超管的用户名(只显示“超级管理员”),查询以超管为根的树得到“不存在”。

## 剪枝(替代链式封禁) <span class="badge-built">已实现</span>

按**每个节点的高度**从下往上剪:叶子高度 0,其余为 1 + 最高子节点;高度按完整子树计算(含管理员、已停用、已删除)。剪掉子树里高度小于 N 的普通用户;整棵树不足 N 层则整棵(含根)被剪。N 默认取配置 `registration.pruneLevels`(默认 3,1–32),对话框可改。管理员与超管**豁免**但不挡路;已被其他来源停用的人不动。效果是“停用”(可回滚),与手动停用一致:会话失效、排入 Emby 同步。

| 步骤 | 展示 | 交互 |
|---|---|---|
| 预览 | 顶部“层数”输入(预填默认值,改动即重新预览);“共 H 层,将剪最下 M 层”;将停用名单、已停用、豁免三组 | 点击红色“剪枝”(需 `admin.users.prune`)先预览,不执行 |
| 确认 | 必填原因 + 输入根用户名;超过 2000 人或没有要剪的人时不能确认 | 确认后执行;子树或层数变化 → 409,自动显示新名单 |
| 结果 | “已剪 N 人,会话已失效;Emby 联动处理中” | 可跳转剪枝记录 |

## 剪枝记录 `/admin/prune-actions`

“用户”页的标签页(`admin.users.read` 可看)。顶部“默认层数”行(有 `admin.config.write` 才能改)。每条记录:编号、根用户、层数、人数、原因、操作人与时间、状态;有 `admin.users.prune` 者可对未回滚的记录“回滚”(必填原因),结果“恢复 N 人,仍被其他原因停用 M 人”;重复回滚 409。

## 状态与边界

- 目标用户在操作中被他人修改：409，提示刷新。
- Emby 联动失败：剪枝已生效，页面显示“联动重试中”，并链接到系统的任务队列。
- 空列表：显示筛选条件并提供“清除筛选”。

## 依赖接口

`/admin/users*`、`/admin/users/{id}/tree`、`/admin/users/{id}/prune/preview`、`/admin/users/{id}/prune`、`/admin/prune-actions`、`/admin/prune-actions/{id}/rollback`、`/admin/config/registration`、`/super/admins`。
